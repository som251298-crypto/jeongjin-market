서울정진학교 정진시장 설치 안내

1. ZIP 파일을 압축 해제합니다.
2. PC에서 바로 확인: index.html을 Chrome 또는 Edge로 열면 상품 검색, 분류, 수량, 장바구니, 영수증 기능을 사용할 수 있습니다.
3. 휴대폰/태블릿에 '앱 설치'하려면 폴더 전체를 HTTPS 웹서버에 올려야 합니다. ZIP 파일을 직접 열거나 file:// 주소로 열면 PWA 설치가 되지 않습니다.
4. HTTPS 주소 접속 후:
   - Android Chrome: 브라우저 메뉴 → 앱 설치 / 홈 화면에 추가
   - iPhone/iPad Safari: 공유 → 홈 화면에 추가
   - PC Chrome/Edge: 주소창 설치 아이콘 또는 메뉴 → 앱 설치
5. 설치 후 한 번 정상 접속하면 오프라인에서도 실행할 수 있습니다(브라우저 저장 데이터 삭제 시 재접속 필요).
6. 장바구니는 기기별 브라우저에 따로 저장됩니다. 다른 기기와 동기화되지 않습니다.
7. 결제하기는 영수증 표시 기능이며 실제 카드/계좌 결제는 처리하지 않습니다.
8. 각 기기에서 동일한 앱을 설치하려면 동일한 HTTPS 주소를 사용하세요.
